실험 기능

에이전트끼리 협업하기

에이전트 하나가 총괄이 되어 일을 나누고, 다른 에이전트가 일한 결과를 하나로 모아 줘요. 기본은 꺼져 있어요.

  1. 스위치를 켜요. 설정 → 실험 기능 → 협업 규칙을 켜면 사용법 안내 창이 떠요.
  2. 첫 입력을 "협업:"으로 시작해요. 예: 협업: 로그인 화면을 만들어 줘
  3. 그 세션이 총괄이 돼요. 총괄은 역할을 나누고, 계획을 보여 주고, 일하는 에이전트(워커) 세션에 작업 지시서를 보내요. 끝나면 결과를 하나로 모아 알려 줘요.
🧭

역할 나누기

연결된 에이전트(Claude·Codex 등)에 맞게 총괄이 역할을 정해요.

📝

작업 지시서

워커 세션은 지시서만 받으면 일할 수 있어요.

📋

결과 한 번에

워커가 끝낸 일을 총괄이 모아서 한 번에 보고해요.

세션의 첫 입력만 봐요. 대화 중간에 "협업"이라는 말이 나와도 규칙은 켜지지 않아요. 스위치가 꺼져 있으면 평소처럼 동작하고, "협업 규칙이 꺼져 있다"고 한 줄로 알려 줘요. 협업 규칙은 1.0.1부터 정상 동작해요 (1.0.0에서는 켜도 적용되지 않았어요).

설치

3단계면 끝나요

Windows 10 · 11 에서 쓸 수 있어요.

  1. 받기
    madang-windows-setup.exe를 받아요. 다른 버전은 이전 버전에서 받을 수 있어요.
  2. 실행
    파일을 실행하면 설치가 끝나요. "PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러 주세요.
  3. 시작
    Madang을 열고 프로젝트 추가를 눌러 폴더를 고르면 시작해요.
  • 이 베타는 코드 서명이 없어서 Windows가 경고를 보여요.
  • 1.0 이상 정식 버전은 앱이 새 버전을 확인해 알려 줘요. 베타(1.0.0-beta.*)는 이 사이트에서 직접 받아 주세요.
  • 지금은 Windows용 설치 파일만 있어요.
